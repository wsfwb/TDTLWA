# Phase E24 — Direct Responses API isolation

E24 re-tests the fixed E22 interface hypothesis using stateless direct
Responses API requests. It does not use Codex `exec`, shell, browser,
computer, function tools, workspace state or previous responses. Model and
effort are fixed to `gpt-5.6-sol` and `xhigh`; temperature is 0.0. Interfaces
run sequentially I1 → I2 → I3. I4 and raw multimodal I5 are not run.

This is a same-split, test-selected, post-hoc exploratory result. It is not a
clean deployment estimate, unbiased generalization estimate or untouched-test
evaluation. Session-5 gold is read only after complete valid interface caches
for post-hoc candidate evaluation.
